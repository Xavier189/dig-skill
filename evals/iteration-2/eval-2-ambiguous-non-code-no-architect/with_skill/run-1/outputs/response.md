**我的当前假设**

- **你真正想要的**：找出近期协作混乱背后的少数关键机制问题，并让团队恢复清晰的责任、沟通和决策方式。
- **最容易失败的地方**：一是把“协作乱”泛化成所有人轮流吐槽，最后只得到“加强沟通”；二是当众追责导致大家回避真实问题。
- ✅ **明确**：要策划一次部门复盘会，目标是解决问题，不是走形式。
- 🔍 **待你确认**：我会默认聚焦 1–2 个反复发生、影响最大的协作问题，不做面面俱到的部门总结。
- 🔍 **待你确认**：我会默认采用“会前收集事实 → 会中还原模式 → 当场拍板改变 → 会后复查”的闭环。
- ❓ **尚不明确**：这次首先要修的是工作机制、团队信任，还是某次具体事件留下的问题。
- ❓ **尚不明确**：现场是否有权直接决定负责人、规则和资源调整。

请按题号回答，选字母即可，也可以补一句背景：

1. **复盘后 30 天，你最希望看到哪一种变化？**（决定会议的主轴）
   - A. 职责、接口和决策规则变清楚，类似混乱明显减少
   - B. 大家敢把真实分歧说出来，信任关系得到修复
   - C. 把某次关键事件讲清楚，避免同类事件重演
   - **推荐 A**：你描述的是持续性的“协作有点乱”，优先修工作机制通常最可落地；若已有明显对立，则改选 B。

2. **“协作乱”最典型的表现是什么？**（可多选，决定案例与讨论范围）
   - A. 优先级反复变化、决策没人拍板
   - B. 职责边界不清、事情互相等待或重复做
   - C. 信息不同步、跨团队交接经常丢失
   - D. 冲突被压住或演变成互相指责
   - **推荐只选最影响结果的 1–2 项**，避免把会议开成问题清单大会。

3. **团队目前对公开讨论问题的安全感如何？**（决定采用全员讨论、匿名输入还是小组访谈）
   - A. 能直接争论事情，不太会针对个人
   - B. 表面和气，但很多人不会在会上说真话
   - C. 已有明显对立、甩锅或上下级压力
   - **推荐**：若是 B，采用匿名会前收集；若是 C，不建议直接开全员自由讨论，应先做小范围访谈并设置中立主持。

4. **谁能在现场对改变作出承诺？**（决定会议产出是“正式决策”还是“待审批方案”）
   - A. 部门负责人和关键协作方都会参加，可以当场拍板
   - B. 部门内部能拍板，但跨部门事项只能提议
   - C. 主要是团队成员参加，负责人只听结果或不参加
   - **推荐 A**：没有决策权的人在场，复盘很容易停在共识；若只能选 B/C，我会把升级路径和审批责任人纳入成功标准。
