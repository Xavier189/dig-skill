# dig 运行期观察记录

运行中遇到 README「观察期」清单里的任一情况，按模板追加一条。攒够一批（或出现高频模式）后，据此迭代 description / SKILL.md，发布 v2。

分类取值：`漏触发` | `误触发` | `问题质量` | `烦人度` | `纪要质量` | `plan联动` | `loop收敛` | `假设质量` | `context成本` | `其他`

完整案例（含会话原文）存 `case/local-case-*.md`——文件名带 `local` 前缀即被 .gitignore 的 `local*` 覆盖，**不入公开仓库**（案例常含内部代码细节）；本文件中的记录只写脱敏摘要。

## 记录模板

```markdown
### YYYY-MM-DD <一句话场景>
- 分类：
- 当时的指令原文：
- 期望行为：
- 实际行为：
- 备注（可选）：
```
